# Glossary

[Wiki home](../README.md)

| Term | Meaning |
|---|---|
| Source | One independently loaded dataset and its status |
| Loader | Function in `LOADERS` that fetches and parses a source |
| Outlet / tier | A publisher and its credibility level |
| Article / story | One feed item / a group of items about one event |
| Archive | Recent news kept on the device |
| Transfer entry | A tracked transfer storyline |
| Stepper | Rumour → Talks → Agreed → Complete |
| Match phase | Live, completed, postponed, upcoming, kickoff-passed, unconfirmed |
| Hero | The large match card |
| Stale | Saved data older than the latest attempt |
| Memo / response cache | In-memory cache of responses |
| TTL | How long a cached response is reused |
| LRU | Least recently used eviction |
| CORS proxy | Third-party relay used when the browser may not call a host directly |
| Circuit breaker | Temporarily skipping a failing proxy |
| Cooldown | Pause after a rate limit |
| Fixture (tests) | Recorded provider response |
| Fixture (football) | Upcoming match |
| WSL | Women's Super League |
